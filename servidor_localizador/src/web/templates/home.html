Sistema de localización Indoor

Plataforma de localización mediante redes Wi-Fi. Administrá el muestreo de señales, entrená modelos de redes neuronales y realizá predicciones de ubicación.

Acerca del sistema

El sistema utiliza mediciones de intensidad de señal recibida (RSSI) de redes Wi-Fi, usando su BSSID para identificarlas, para estimar la ubicación de dispositivos dentro de un entorno cerrado, mediante modelos de aprendizaje automático.
